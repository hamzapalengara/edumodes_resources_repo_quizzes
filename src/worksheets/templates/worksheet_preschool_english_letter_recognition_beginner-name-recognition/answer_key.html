Answer Key: Name Recognition Adventure

Activity 1: Name Input

Expected Outcome:

  • Parent enters child's name correctly
  • Name is converted to uppercase letters
  • Progress bar shows 20% completion
  • First star is awarded

Activity 2: Letter Recognition

Expected Actions:

  • Child finds and clicks each unique letter in their name from the alphabet grid
  • Letters highlight when correctly identified
  • Progress advances to 40% when all unique letters are found
  • Second star is awarded upon completion

Activity 3: Letter Matching

Correct Matching Process:

  • Each letter in the name appears twice in the matching grid
  • Cards remain face-up when correctly matched
  • Progress reaches 60% when all pairs are matched
  • Third star is awarded upon completion

Activity 4: Letter Sequencing

Correct Sequence:

  • Letters must be selected in the exact order they appear in the name
  • Incorrect selections are indicated with a shake animation
  • Progress advances to 80% when name is correctly sequenced
  • Fourth star is awarded upon completion

Activity 5: Letter Animation

Expected Interactions:

  • Each letter shows correct stroke order when clicked
  • All unique letters must be viewed
  • Progress reaches 100% when all animations are viewed
  • Fifth star is awarded upon completion

Assessment Notes

The worksheet is considered complete when:

  • All five activities are completed in sequence
  • All five stars have been earned
  • Progress bar shows 100%
  • Child demonstrates understanding of their name's letters and sequence
