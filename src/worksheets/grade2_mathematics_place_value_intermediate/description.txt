An engaging intermediate-level worksheet that challenges Grade 2 students to master place values through advanced problem-solving. Features include:

• Rearranging digits to create specific numbers (largest, smallest, within ranges)
• Identifying numbers based on place value conditions
• Working with zeros in different positions
• Adding and subtracting with place values
• Comparing numbers and finding closest values

Learning Objectives:
- Master strategies for creating largest and smallest possible numbers
- Understand how digit placement affects number value
- Work confidently with numbers in specific ranges
- Develop problem-solving skills with place values
- Build number sense and mental math abilities

Perfect for students who have mastered basic place value concepts and are ready for more challenging problems. Includes comprehensive answer key with detailed explanations and common mistake warnings. Interactive features include immediate feedback, voice guidance, and celebration animations.
